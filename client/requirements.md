## Packages
@syncfusion/ej2-react-gantt | Gantt chart component for task scheduling
@syncfusion/ej2-react-kanban | Kanban board component for workflow management
@syncfusion/ej2-react-layouts | Splitter component for dashboard layout
@syncfusion/ej2-base | Core Syncfusion base library
@syncfusion/ej2-data | Data handling for Syncfusion components
@syncfusion/ej2-react-base | React wrapper for Syncfusion base
recharts | For dashboard metrics visualization

## Notes
Syncfusion requires registering a license key in some environments, but community license works for development.
Dates from API need to be converted to JS Date objects for Syncfusion components.
Syncfusion CSS files must be imported globally.
Dashboard layout uses a splitter to organize metrics and previews.
